# Ford Drive Launcher — نسخة أولية

واجهة أندرويد عربية أفقية لشاشات السيارات، مع شاشة افتتاحية بالشعار، ساعة وتاريخ، وواجهة كبيرة للمس.

## طريقة إنشاء ملف APK
1. ثبّت Android Studio على الكمبيوتر.
2. افتح مجلد `Ford_Drive_Launcher` باستخدام **Open**.
3. انتظر اكتمال مزامنة Gradle وتنزيل أدوات Android SDK اللازمة.
4. اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. ستجد ملف التثبيت غالباً في `app/build/outputs/apk/debug/app-debug.apk`.
6. انقل APK إلى شاشة السيارة وثبّته (بعد السماح بتثبيت التطبيق من المصدر المناسب).

## الوظائف
- شاشة شعار Ford عند تشغيل التطبيق (يمكن تعطيلها من الإعدادات).
- أزرار الخرائط والموسيقى والهاتف والبلوتوث وإعدادات الجهاز والتطبيقات.
- المظهر الليلي/النهاري والساعة 12/24.
- تعمل دون إنترنت للواجهة؛ الخرائط وخدمات الموسيقى تعتمد على التطبيقات أو الاتصال.

## ملاحظات
- هذه **نسخة أولية قابلة للبناء** وليست ملف APK مبنياً؛ لم تتوفر أدوات Android SDK في بيئة إعداد المشروع هنا.
- واجهة بدء التشغيل تظهر عند **فتح التطبيق**، وليس عند ظهور شعار نظام أندرويد/إقلاع الجهاز نفسه.
- تشغيل التطبيق تلقائياً بعد تشغيل السيارة يتطلب دعم شاشة السيارة لخيار Auto Start أو تعيين تطبيق كواجهة رئيسية من إعدادات الجهاز، وقد يختلف حسب الشركة والنظام.
- الأزرار تفتح التطبيقات/الإعدادات الخارجية، ولا تتصل مباشرة بحساسات السيارة أو CAN bus أو كاميرا الرجوع.
- شعار Ford مستخدم لتخصيص شخصي؛ التطبيق غير تابع لشركة Ford.
- بعض شاشات أندرويد المعدّلة قد تختلف فيها أسماء حزم التطبيقات، ويمكن تعديل الربط داخل MainActivity.java.
